## Programming Fundamentals

### Project
Sum of First 50 Natural Numbers

### Description
This C++ program uses a for loop to calculate
the sum of natural numbers from 1 to 50.

### Formula
Sum = n * (n + 1) / 2

For n = 50:

Sum = 50 * 51 / 2 = 1275

### Expected Output
Sum of first 50 natural numbers (loop): 1275

### Language
C++
